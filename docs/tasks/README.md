# Tasks

This folder contains task management documents for the Dokploy Enhanced project.

## Purpose

Track development tasks, bugs, enhancements, and maintenance work in a structured format.

## File Naming Convention

```
YYYY-MM-DD-short-description.md
```

Examples:
- `2024-01-15-add-arm64-support.md`
- `2024-01-20-fix-traefik-ssl-renewal.md`

## Task Template

```markdown
# Task: [Title]

## Status
- [ ] Not Started
- [ ] In Progress
- [ ] Blocked
- [ ] Completed

## Priority
High / Medium / Low

## Description
[Detailed description of the task]

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Notes
[Any additional notes, blockers, or context]

## Related
- Issue: #123
- PR: #456
```

## Task Categories

| Category | Description |
|----------|-------------|
| `feature` | New functionality |
| `bug` | Bug fixes |
| `enhancement` | Improvements to existing features |
| `docs` | Documentation updates |
| `chore` | Maintenance and housekeeping |
| `security` | Security-related tasks |
